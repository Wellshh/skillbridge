
This directory hierarchy contains Allegro AXL Skill documentation
updates since the RTM of the release. It has two sub-directoriews:
    - CHANGE: modifications to existing documentation. This can
	be API modifications and document clarifications.
    - NEW: new Allegro AXL APIs in the release.

These updates are not contained within the CdnsHelp documentation.
The CdnsHelp document will be updated in the next major release.
